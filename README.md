## Project Overview
Checkers is a retail website prototype for a supermarket brand. The website showcases the company profile, services, products, and contact information while using responsive design and modern visual styling.

## Part 2 Enhancements
- Added a global stylesheet (`style.css`) that defines typography, spacing, color system, and responsive layout.
- Implemented a mobile-first navigation structure with interactive hover and focus states.
- Created responsive layouts using CSS Flexbox and Grid for product cards and page structure.
- Applied typography scale with `font-family`, `font-size`, `font-weight`, `line-height`, and `letter-spacing`.
- Added responsive image markup using `srcset` and `sizes` to improve loading behavior.
- Defined breakpoints for desktop, tablet, and mobile views using media queries.

## Website Goals and Objectives
- Present the Checkers brand with a clear, accessible interface.
- Support multiple screen sizes with responsive design.
- Improve readability and navigation using modern typography and layout.
- Provide a polished product listing, contact form, and consistent page styling.
